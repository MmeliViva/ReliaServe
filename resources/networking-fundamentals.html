Networking Fundamentals: How Devices Connect

Understand the building blocks that move information across local networks and the internet.

What is computer networking?

Computer networking connects devices so they can exchange information. A Local Area Network (LAN) generally covers a limited location, while a Wide Area Network (WAN) connects networks across larger distances. A Metropolitan Area Network (MAN) covers a city or campus-scale region, and a Personal Area Network (PAN) covers very short-range personal devices.

Routers, switches and access points

A switch forwards traffic between known devices on the same network segment. A router connects different networks and chooses paths between them. A wireless access point provides Wi-Fi connectivity to a wired network. A home router often combines these functions with DHCP, firewall and Wi-Fi features, but the functions remain distinct.

IP addresses and DNS

An IP address identifies a network interface. IPv4 addresses are usually written in dotted decimal form, while IPv6 uses hexadecimal groups. DHCP automatically assigns addresses and network settings to many devices. A domain name is not an IP address; DNS converts a name to relevant records.

TCP versus UDP

TCP, or Transmission Control Protocol, establishes a connection and provides ordered, acknowledged delivery. It is often used where completeness matters. UDP, or User Datagram Protocol, sends datagrams without TCP-style delivery acknowledgements and is useful for latency-sensitive services such as voice or certain real-time applications.

Neither protocol is automatically “better.” The application requirements determine the suitable transport. Protocol numbers and service ports—for example TCP 443 for HTTPS—provide additional routing information, but firewall rules must not rely on names alone.

The OSI model

The OSI model is a conceptual seven-layer framework: Physical, Data Link, Network, Transport, Session, Presentation and Application. It helps diagnose issues by separating concerns—for example, physical cabling, address routing, transport delivery and application behaviour.

Practical real-world example

South African office scenario: Staff cannot open a hosted accounting website. A network technician first checks whether devices have an address, tests DNS resolution, verifies a route or gateway and then examines firewall or application availability. This avoids assuming the hosting service is at fault immediately.

Network security fundamentals

  • Use unique admin credentials and apply least privilege.
  • Segment guest, staff and sensitive systems where appropriate.
  • Update network firmware and disable unused services.
  • Restrict management interfaces and log configuration changes.
  • Encrypt sensitive remote access and review firewall rules regularly.

Common misconceptions

“The internet and a WAN are the same.” The internet is a global collection of interconnected networks; a WAN is a type of network that can include private links. “A faster cable always fixes network speed.” Bottlenecks can occur in Wi-Fi, DNS, routing, bandwidth or application design.

Frequently asked questions

What is a default gateway?

A default gateway is a router or system address used when a device needs to send traffic outside its local network or known routes.

Does DHCP provide internet access itself?

No. DHCP distributes local network settings. Internet access additionally depends on routing, firewall policy and the provider connection.

Key takeaways

Networking combines addressing, switching, routing, naming and transport protocols. Diagnostic steps are most effective when you isolate the layer or component likely to be failing.
